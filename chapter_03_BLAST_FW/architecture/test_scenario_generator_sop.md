# SOP: Test Scenario Generator

## Goals
Build a React UI (Next.js) that accepts Jira and Groq credentials via the UI, inputs a Jira ID, fetches the issue and its attachments, and outputs a test scenario strategy generated by Groq's LLM.

## Inputs
- Jira Base URL
- Jira Email
- Jira API Token
- Groq API Key
- Target Jira ID (e.g., KAN-4)

## Architecture (3-Layer)
1. **Frontend (React/Tailwind):** The "Configuration" panel gathers all secrets. The "Generate" panel takes the Jira ID. The secrets and the ID are POSTed to the Next.js backend route.
2. **Backend (Next.js API Route):** Acts as the navigation layer. It receives the secrets. It first calls the Jira API (Layer 3 logic) using the provided credentials. It extracts the ticket text and attachments. Then it calls the Groq API (Layer 3 logic) using the provided Groq key to generate scenarios.
3. **Tools (Backend Helpers):** 
   - `fetchJiraData`: Uses Axios + Jira token to get issue details and download attachment text.
   - `generateScenarios`: Uses Groq SDK + Groq key to format prompt and generate markdown output.

## Edge Cases
- Missing credentials: UI validation should block submission.
- Jira Attachment Parsing: If attachment is binary (e.g. DOCX), the backend must parse it (we will implement basic parsing or extract text if it's plaintext/markdown/PDF if supported, or warn if unparseable).
- Network Failure: Proper try/catch and error states in UI.
